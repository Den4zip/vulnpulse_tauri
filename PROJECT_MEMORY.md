# VulnPulse Tauri — состояние проекта

Обновлено: 2026-11-19. Источник: запрос пользователя продолжить с текущего этапа, [PLAN.md](PLAN.md), фактические файлы и локальные проверки.

## Принятые решения

- Пользователь выбрал новый проект на Tauri/Rust/TypeScript с сохранением лучших функций и дизайна. Tauri заменяет Electron. Рабочая папка: `D:\проект\vulnpulse-tauri`.
- Основной план — [PLAN.md](PLAN.md), правила — [AGENTS.md](AGENTS.md). Уточнения библиотек, формата Vault и методики риска в плане являются будущими решениями, а не проверенной реализацией.
- Перенесены три подтверждённых правила: upgrade сохраняет установку, перенос создаёт новую; пересчёт не меняет ручной статус; legacy-заметки/SLA назначаются finding только отдельным действием.

## Фактическое состояние

- Этап 0 продолжается в `develop`. Node.js 24.21.0 и Rust 1.100.0 зафиксированы. Зависимости записаны в npm и Cargo lockfiles. Публичный remote `https://github.com/Den4zip/vulnpulse_tauri` подключён как `origin`.
- Экран демонстрационного каталога читает две синтетические записи через `list_demo_catalog`. Rust проверяет лимит, выполняет SQLite вне async executor и ограничивает параллелизм одним запросом. SQL-миграция включена в приложение и применяется транзакционно с проверкой SHA-256. Временная SQLite создаётся в памяти, типы TypeScript генерируются из Rust через ts-rs.
- Команда внесена в Tauri AppManifest и разрешена capability основного окна. Установлены CSP и ограничения навигации. Добавлены Windows workflow с NSIS, Edge WebDriver smoke с отдельным профилем и тестовый конфиг для проверки отказа IPC. Команды и методика проверок — в [заметках этапа 0](docs/windows-stage-0.md).
- История прежнего репозитория сохранена в `references/legacy-history.bundle`, включая `c44d73605985dff7b9c8fadc929a06efa3c6c068`. Git сообщил полную историю и успешную проверку bundle. Пользовательские БД, секреты и игнорируемые файлы туда не входят.
- Старый проект сохранён. Его рабочая ветка `develop` чистая и на один коммит впереди локального `origin/develop`. Отправка исправления Electron CI ранее была прервана; успешный удалённый CI не подтверждён. В этом ходе push/PR не выполнялись.

## Проверки и ограничения

- Прочитаны локальные требования, дизайн, концепция, модель, Vault, CSS, контракты и тестовые сценарии. Просмотрено сохранённое превью Mint. Ссылки на Figma и сведения о лицензии происходят из исследования старого проекта; внутренние слои Figma заново не получены.
- Документы Tauri об архитектуре, разрешениях, WebDriver и окружении проверены в официальных источниках; ограничения custom commands сверены через Context7.
- Проверены 4 Markdown-документа, 34 локальные ссылки внутри пакета, парность блоков кода, отсутствие символов ошибки декодирования и SHA-256/размеры 9 сохранённых материалов — ошибок нет. Проверены `git bundle verify`, восстановление в отдельный bare-репозиторий, `git fsck --full` и точное совпадение HEAD с исходным коммитом. Архив содержит полную Git-историю; восстановленное приложение не собиралось. Контрольные суммы находятся в `references/manifest.json`.
- На Windows 11 Pro x64 установлены Microsoft C++ Build Tools и Windows SDK. После чистого `npm ci` прошли проверка типов, линтер, два frontend-теста, проверка документации и сборка интерфейса. Прошли Rust fmt, Clippy, шесть Rust-тестов, генерация и проверка DTO.
- Собран `src-tauri/target/release/bundle/nsis/VulnPulse_0.1.0_x64-setup.exe` (210,4 МиБ) со встроенным офлайн-установщиком WebView2. В Edge WebDriver 157.0.4341.60 пройдены оба desktop-сценария: релиз загрузил записи из SQLite и отклонил неверный лимит, отдельная сборка отклонила IPC для окна без разрешения. Релиз также проверен через Tab и Enter. Для запуска использован системный PATH без Node.js. В CI подготовка драйвера идёт после установки релиза. Удалённый запуск ещё предстоит зафиксировать.
- Покрытие Rust сформировано с cargo-llvm-cov 0.9.1, совместимым с расположением тестовых файлов Cargo 1.100 на Windows. Сводка unit-тестов: 61,24% строк, 65,82% LLVM regions и 54,55% функций. IPC и application service проверены через WebView2 отдельно от отчёта покрытия.
